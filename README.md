🌐 Simple Portfolio Website
Website portofolio pribadi yang bersih, modern, dan responsif untuk menampilkan profil diri, keahlian (skills), daftar proyek pilihan, serta informasi kontak. Dibangun dengan fokus pada performa cepat, tata letak rapi (clean UI), dan pengalaman pengguna yang mulus di berbagai perangkat.
🔗 Repositori: github.com/carsonroderick/simple-portofolio
---
✨ Fitur Utama
Desain Responsif (Mobile-First): Tata letak otomatis menyesuaikan ukuran layar, mulai dari ponsel (mobile), tablet, hingga monitor desktop.
Navigasi Interaktif: Dilengkapi navbar tetap (sticky/fixed) dengan menu hamburger/drawer khusus untuk tampilan seluler.
Animasi Scroll Halus (Smooth Scroll Reveal): Elemen muncul secara bertahap saat halaman digulir menggunakan Intersection Observer API.
Bagian Profil & Tentang Saya (About): Ringkasan latar belakang, minat, dan fokus pengembangan.
Showcase Proyek (Projects): Galeri kartu proyek lengkap dengan deskripsi singkat, teknologi yang dipakai, serta tautan Live Demo dan Source Code.
Keahlian (Tech Stack & Skills): Daftar bahasa pemrograman, framework, dan alat pengembangan yang dikuasai.
Kontak & Media Sosial: Tautan langsung ke email, GitHub, LinkedIn, maupun media sosial lainnya.
---
🛠️ Teknologi yang Digunakan
HTML5 Semantik — Struktur dokumen web yang terorganisir dan ramah SEO.
Tailwind CSS — Utility-first CSS framework untuk mempercepat proses styling dan desain responsif.
JavaScript (ES6+) — Menangani interaktivitas menu navigasi dan animasi halaman.
(Catatan: Sesuaikan daftar di atas jika kamu menggunakan framework atau alat tambahan seperti Vite, React, atau ikon dari Lucide/FontAwesome).

🚀 Cara Menjalankan Proyek Secara Lokal
Ikuti langkah-langkah berikut untuk menyalin dan menjalankan proyek ini di komputer kamu:
Clone repositori ini:
```bash
   git clone https://github.com/carsonroderick/simple-portofolio.git
   ```
Masuk ke direktori proyek:
```bash
   cd simple-portofolio
   ```
Jalankan proyek:
Jika menggunakan HTML & Tailwind CDN: Buka file `index.html` langsung di browser, atau gunakan ekstensi Live Server di Visual Studio Code.
Jika menggunakan Node.js / Tailwind CLI / Vite:
```bash
     npm install
     npm run dev
     ```
